# Komentář k zákonu č. 198/1993 Sb., o protiprávnosti komunistického režimu a o odporu proti němu

Otevřený komentář k zákonu o protiprávnosti komunistického režimu a o odporu proti němu — § po §: doslovné znění, výklad, kazuistika, protiargumenty a praktický závěr; preambule, odpovědnost a protiprávnost režimu, legitimita odporu, promlčení, zmírnění trestů a zmocnění vlády.

Konsolidované znění: dokument e-Sbírky `SB-1993-00198_2023-03-20`.
